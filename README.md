его описание::

1. При запуске начинает собирать все возможные папки в wstring вектор, со всех возможных дисков.
2. Пропускает папки (и не использует их далее) в которые не может записывать файлы, пропускает системные папки
3. Собирает все файлы со всех дисков, только после этого переходит к п.4
4. Проходит по собранным директориям и создает wstring вектор с найденными файлами (только теми, что не скрыты и не скрыты системно) 
5. Делает n-ное (5) количество копий каждого файла из вектора (из п.4) в папку, где находился этот файл (начинает с диска C)
6. Если есть съемные носители (флешки, диски), то он ищет все .exe файлы на на них, после чего заменяет их на свою копию, а оригинальный файл скрывает (это первый вариант распространения червя).
7. Сохраняет свою копию в созданную скрытую папку на диске C:\
8. Добавляет себя в автозапуск из папки п.7 (работает только с правами администратора + дефендер это видит)
9. Отправляет сообщение на локальный айпишник, на выбранный порт. (нужно в заранее открыть сервер на выбраном порту)

Реализовано, но не до конца:
1. Находит айпишник в локальной сети, находит маску, в wstring вектор выносит возможные айпи адреса подключенных к сети устройств.
2. По найденым айпи адресам находит их открытые порты. (пока что бесполезно, т.к. нужно разобраться в портах и их уязвимостях)


# WormMessageServer (Academic Project)

Реализация учебного сетевого червя на C++ для ОС Windows. Проект демонстрирует механизмы рекурсивного сканирования, саморепликации и заражения съемных носителей.

---

## Алгоритм работы

### 1. Сканирование и фильтрация
Программа инициирует сбор путей всех доступных директорий на всех логических дисках системы.
* **Исключение системных путей:** Пропускаются директории `Windows`, `Program Files`, `System Volume Information` и другие критические узлы ОС.
* **Проверка прав:** Директории, недоступные для записи, игнорируются и не используются в дальнейших циклах.

### 2. Тело червя
После формирования списка доступных папок программа переходит к анализу их содержимого.
* **Фильтрация по атрибутам:** Вектор целей формируется только из файлов, не имеющих атрибутов "Скрытый" или "Системный".
* **Репликация:** Для каждого найденного файла создается 5 копий в той же директории (количество создаваемых копий можно изменить). Каждой копии присваивается уникальное имя (на базе системного времени и рандома), а также устанавливаются атрибуты скрытого системного файла.

### 3. Съемные носители
Программа отслеживает подключение внешних накопителей (флешек, дисков).
* **Подмена EXE:** Выполняется поиск всех исполняемых файлов на носителе.
* **Маскировка:** Оригинальный `.exe` файл скрывается, а на его место записывается копия тела червя под тем же именем.

### 4. Автозагрузка
* **Локальная копия:** Программа копирует свое тело в созданную скрытую папку на диске `C:\`.
* **Автозагрузка:** Выполняется попытка добавления пути к файлу в ключи реестра Windows для автоматического запуска при старте системы (требуются права администратора).

### 5. Сетевой модуль
* **Связь через сервер:** Отправка сетевого сообщения на заданный локальный IP-адрес и порт для подтверждения активности узла.

---

## Сборка и запуск

1. Перейдите в папку проекта:
```powershell
mkdir build
cd build
cmake ..
cmake --build . --config Release
```

Исполняемый файл будет находиться в директории build/Release/WormMessageServer.exe
